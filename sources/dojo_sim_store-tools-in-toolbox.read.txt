Simulation demo
Instruction
Place each tool into its matching position in the toolbox, then reset the robot arm.
Description
There are several tools and a toolbox with designated slots. The robot needs to pick up each tool and place it into the corresponding position in the toolbox.

Scoring
Section titled “Scoring”
Score
Condition
0
No tool is placed into its matching toolbox slot.
25
Any one tool is placed in its matching toolbox slot with the gripper open.
50
Any two tools are placed into their matching toolbox slots.
75
Any three tools are placed into their matching toolbox slots.
100
All four tools are placed in their matching slots, covered by the toolbox, and the robot returns to origin.
