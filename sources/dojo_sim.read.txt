Simulation Tasks
RoboDojo provides a simulation task suite for evaluating robotic manipulation policies in Isaac Sim. The suite currently includes
43 simulation task pages
. The Generalization tasks with random-layout variants show the standard and random demos side by side on the same page.
Each task page includes a demo video, natural-language instruction, task description, platform label, capability category, data source, and intended usage. Use these pages to inspect the expected robot behavior, compare task difficulty, and select scenarios for training or evaluation.
World-axis orientation
Section titled “World-axis orientation”
The axis triad below visualizes the orientation of the simulation world’s coordinate axes:
X
is red,
Y
is green, and
Z
is blue.
World-axis directions visualized in a RoboDojo simulation scene.
Important:
The position where the arrows are drawn is only for visualization. It
does not represent the origin of the world coordinate system
.

Multi-step tasks that require completing several subgoals
Open

Open-ended or language/image-conditioned manipulation tasks

Additional task entry
Random-layout variants use the same task objective as their base task, but change the initial arrangement to test robustness under scene variation.
Related simulation tools:
Domain Randomization
— randomize layout, materials, lighting, and backgrounds to test robustness.
Parallel Environments
— run multiple Isaac Sim environments in one process for higher throughput.
