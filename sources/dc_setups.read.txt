How each task is set up, reset and scored
One card per task: the props, the start state, how it is reset between trials, the exact instruction
    the model gets, the scoring rubric, and the photos. The large photo is the overhead camera at full resolution, as
    the judges see it; the three small ones are what the model gets after every step.
Same for every task
Two I2RT YAM arms, end-effector position control at a quarter of full speed, homed to the same start pose.
Three cameras: overhead and one on each wrist. The model gets all three at 224 × 224 after every step and keeps
        the last two steps' images; the judges get full-resolution photos from all three, before the trial and after the
        arms park.
At most 40 model calls per trial, no time limit, 65 °C motor-temperature cutoff.
The props start in the same place and state every trial; the helper resets each rig against its reference photo
        from the phone page.
Three trials per model per task, nine models, with the models taking turns.
What the model gets
The same system prompt and tools for every task and model. Only the goal changes: each card's
      instruction, sent once as the goal and again with every observation.
